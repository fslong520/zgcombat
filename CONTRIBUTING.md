##Contributing to CodeCombat

There are many ways in which to contribute to CodeCombat, these include becoming a(n):

 - **[Archmage](https://flsong.iok.la/contribute/archmage)** (Coder)
 - **[Artisan](https://flsong.iok.la/contribute/artisan)** (Level Builder) 
 - **[Adventurer](https://flsong.iok.la/contribute/adventurer)** (Level Playtester)
 - **[Scribe](https://flsong.iok.la/contribute/scribe)** (Article Editor)
 - **[Diplomat](https://flsong.iok.la/contribute/diplomat)** (Translator)
 - **[Ambassador](https://flsong.iok.la/contribute/ambassador)** (Support)

###The CLA

If you do decide to contribute, we require you to sign a CLA (Contributor License Agreement).  You can see it:

**[https://flsong.iok.la/cla](https://flsong.iok.la/cla)**

It just grants us a non-exclusive license to use your contribution and certifies you have the right to contribute the code you submit. For both our sakes, we need this before we can accept a pull request. Don't worry, it's super easy.

For more info on the legal side of contributing to CodeCombat, see [https://flsong.iok.la/legal](https://flsong.iok.la/legal).
